# Qwen

A [Next.js](https://nextjs.org) starter with TypeScript and [Tailwind CSS](https://tailwindcss.com), deployed on [Vercel](https://vercel.com).

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the app. Edit `src/app/page.tsx` to get started — the page hot-reloads as you save.

## Deployment

Pushes to `main` deploy to production on Vercel automatically; pushes to any other branch create preview deployments.
